# 离线建库与在线检索数据流

## 总览

```text
═══════════════════════════════════════════════════════
             离线建库与在线检索数据流
═══════════════════════════════════════════════════════

【离线建库阶段】 batch_extract.py（一次性执行）
─────────────────────────────────────────────────────

  ┌───────────────────────────────────────┐
  │ 原始音频文件库  data/raw/             │
  │   ├── song1.mp3  (3.5 MB)             │
  │   ├── song2.wav  (5.2 MB)             │
  │   └── ... 约 8000 首                  │
  └───────────────────┬───────────────────┘
                      │
                      ▼
  ┌───────────────────────────────────────┐
  │ librosa.load()                        │
  │   sr=22050, duration=30.0             │
  │   输出: y (661500 点)                 │
  └───────────────────┬───────────────────┘
                      │
                      ▼
  ┌───────────────────────────────────────┐
  │ 滑动窗口切片                          │
  │   5 秒窗口, 1 秒步长                  │
  │   共 25 个窗口                        │
  └───────────────────┬───────────────────┘
                      │
                      ▼
  ┌───────────────────────────────────────┐
  │ 每个窗口执行信号处理:                 │
  │   ① Mel 频谱 (128 × 216)              │
  │   ② power_to_db()                     │
  │   ③ 转 PyTorch 张量                   │
  │   ④ AudioHashNet 推理 → 128 维浮点    │
  │   ⑤ 动态中值二值化 → 128 位 0/1       │
  │   ⑥ packbits → 16 字节哈希            │
  └───────────────────┬───────────────────┘
                      │
                      ▼
  ┌───────────────────────────────────────┐
  │ 同时写入 Faiss + SQLite               │
  │   Faiss : index.add(哈希)             │
  │   SQLite: INSERT INTO songs           │
  └───────────────────┬───────────────────┘
                      │
                      ▼
  ┌───────────────────────────────────────┐
  │ 原子性提交                            │
  │   写临时索引 → 提交事务               │
  │   一次性替换正式索引和表              │
  └───────────────────┬───────────────────┘
                      │
                      ▼
  ┌───────────────────────────────────────┐
  │ 最终产物                              │
  │   music_hash.index   (~3.2 MB)        │
  │   music_hash.db      (songs 表)       │
  └───────────────────────────────────────┘


【在线检索阶段】 search.py（每次查询执行）
─────────────────────────────────────────────────────

  ┌───────────────────────────────────────┐
  │ 用户上传音频  upload.mp3              │
  └───────────────────┬───────────────────┘
                      │
                      ▼
  ┌───────────────────────────────────────┐
  │ librosa.load()                        │
  │   sr=22050, duration=15.0             │
  │   输出: y (330750 点)                 │
  └───────────────────┬───────────────────┘
                      │
                      ▼
  ┌───────────────────────────────────────┐
  │ 能量选秀 (RMS 筛选)                   │
  │   滑动窗口 → Top 3 最高能量           │
  │   过滤静音 / 淡入淡出                 │
  └───────────────────┬───────────────────┘
                      │
                      ▼
  ┌───────────────────────────────────────┐
  │ 3 个窗口分别处理 (与建库流程相同)     │
  │   ① Mel 频谱    ② power_to_db         │
  │   ③ 转张量      ④ CNN 推理            │
  │   ⑤ 二值化      ⑥ packbits            │
  └───────────────────┬───────────────────┘
                      │
                      ▼
  ┌───────────────────────────────────────┐
  │ 3 个查询哈希 [hash1, hash2, hash3]    │
  └───────────────────┬───────────────────┘
                      │
            ┌─────────┴─────────┐
            ▼                   ▼
  ┌──────────────────┐  ┌────────────────────┐
  │ Faiss 检索       │  │ SQLite 反查        │
  │  search(k=150)   │  │  faiss_id → 元数据 │
  │  返回候选列表    │  │  返回歌曲信息      │
  └────────┬─────────┘  └──────────┬─────────┘
           │                       │
           └───────────┬───────────┘
                       ▼
  ┌───────────────────────────────────────┐
  │ 歌曲级聚合 (同一首歌取最小汉明距离)   │
  └───────────────────┬───────────────────┘
                      │
                      ▼
  ┌───────────────────────────────────────┐
  │ 返回 Top 5 结果                       │
  └───────────────────┬───────────────────┘
                      │
                      ▼
  ┌───────────────────────────────────────┐
  │ 前端展示                              │
  │   - 渲染歌曲列表                      │
  │   - WaveSurfer 波形                   │
  │   - 播放器试听                        │
  └───────────────────────────────────────┘


【共享资源】 系统启动时加载
─────────────────────────────────────────────────────

  ┌───────────────────────────────────────┐
  │ Faiss 索引                            │
  │   ├── 20 万条哈希指纹 (16 字节/条)    │
  │   ├── 总大小: ~3.2 MB                 │
  │   ├── 索引类型: IndexBinaryFlat       │
  │   └── 作用: 毫秒级相似度检索          │
  └───────────────────────────────────────┘

  ┌───────────────────────────────────────┐
  │ CNN 模型                              │
  │   ├── 架构: AudioHashNet              │
  │   ├── 权重: hash_model_v2_epoch_10    │
  │   ├── 输出: 128 维浮点 → 128 位哈希   │
  │   └── 作用: 频谱图 → 哈希指纹         │
  └───────────────────────────────────────┘

  ┌───────────────────────────────────────┐
  │ SQLite 数据库                         │
  │   ├── 文件: music_hash.db             │
  │   ├── songs 表: 20 万条元数据         │
  │   ├── 字段: faiss_id, title, artist,  │
  │   │         file_path, offset         │
  │   └── 作用: faiss_id → 歌曲信息映射   │
  └───────────────────────────────────────┘
```

## 两个阶段的完整交互

```text
┌──────────────────────────────────────────────────────┐
│                两个阶段的完整交互                    │
└──────────────────────────────────────────────────────┘

    ┌─────────────────────┐         ┌─────────────────────┐
    │   离线建库阶段      │         │   在线检索阶段      │
    │  batch_extract.py   │         │     search.py       │
    └──────────┬──────────┘         └──────────┬──────────┘
               │                               │
               │ ① 写入 20 万条哈希指纹        │
               │    (16 字节 / 条)             │
               ├──────────────────────────────►│
               │                               │
               │                               │ ② 读取 Faiss 索引
               │                               │    汉明距离匹配
               │                               │    返回 faiss_id
               │                               │
               │ ③ 写入 songs 元数据表         │
               │    (faiss_id, title, ...)     │
               ├──────────────────────────────►│
               │                               │
               │                               │ ④ 读取 SQLite 数据库
               │                               │    faiss_id → 元数据
               │                               │    返回歌曲信息
               │                               │
               ▼                               ▼
    ┌─────────────────────────────────────────────────────┐
    │                    共享存储层                       │
    ├─────────────────────────────────────────────────────┤
    │                                                     │
    │   ┌─────────────────────┐   ┌─────────────────────┐ │
    │   │ music_hash.index    │   │ music_hash.db       │ │
    │   │ (Faiss 二进制索引)  │   │ (SQLite 数据库)     │ │
    │   │                     │   │                     │ │
    │   │ • 20 万条哈希指纹   │   │ • songs 表          │ │
    │   │ • 大小 ~3.2 MB      │   │   20 万条记录       │ │
    │   │ • IndexBinaryFlat   │   │ • 字段 faiss_id,    │ │
    │   │ • 汉明距离检索      │   │   title, artist,    │ │
    │   │                     │   │   file_path, offset │ │
    │   │                     │   │ • faiss_id 反查     │ │
    │   └─────────────────────┘   └─────────────────────┘ │
    │                                                     │
    │   系统启动时加载                                    │
    │                                                     │
    └─────────────────────────────────────────────────────┘

数据流向说明:
──────────────────────────────────────────────────────

  ① 离线建库 → Faiss 索引
       源头: batch_extract.py (index.add)
       对象: music_hash.index
       内容: 20 万条 16 字节哈希指纹
       频率: 一次性 (模型更新后)

  ② Faiss 索引 → 在线检索
       源头: music_hash.index (index.search)
       对象: search.py
       内容: 返回 Top-K 候选的 faiss_id
       频率: 每次查询

  ③ 离线建库 → SQLite 数据库
       源头: batch_extract.py (INSERT)
       对象: music_hash.db.songs 表
       内容: 20 万条元数据记录
       频率: 一次性 (模型更新后)

  ④ SQLite 数据库 → 在线检索
       源头: music_hash.db.songs 表 (SELECT)
       对象: search.py
       内容: faiss_id → 歌曲信息映射
       频率: 每次查询
```

## 关键差异

| 维度 | 离线建库 | 在线检索 |
|------|---------|---------|
| 音频来源 | data/raw/ (约8000首) | 用户上传 (1个) |
| 音频时长 | 30 秒 | 15 秒 |
| 窗口数量 | 25 个/首 | 3 个 |
| 窗口选择策略 | 滑动窗口 (5秒窗口, 1秒步长) | 能量选秀 (RMS筛选Top 3) |
| 总窗口数 | 20 万 | 3 |
| 数据增强 | 无 | 无 |
| Faiss 操作 | index.add() (写入) | index.search() (读取) |
| SQLite 操作 | INSERT (写入元数据) | SELECT (读取元数据) |
| 输出 | 索引文件 (music_hash.index + music_hash.db) | Top 5 结果 (JSON) |
| 执行频率 | 一次性 (模型更新后) | 每次查询 |
| 执行时间 | 数小时 | 毫秒级 |
| 目的 | 构建检索索引 | 返回相似歌曲 |
